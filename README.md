# 일곱 개의 방

1927년 뉴올리언스부터 2004년 서울까지, 방 일곱 개를 하나의 복도에 모았습니다.
위쪽 탭으로 옮겨 다닙니다. **소리가 본체이므로 헤드폰을 권합니다.**

**https://sylvanus4.github.io/rooms/**

| 연도 | 방 | 만지는 것 |
|---|---|---|
| 1927 | 클럽 | 어디 앉을지와 몇 시인지를 고릅니다 |
| 1979 | 다방 | 쪽지에 기분과 사연을 조합해 DJ 박스에 넣습니다 |
| 1992 | 오락실 | 사람이 몇 명인지를 바꿉니다 |
| 1996 | 할머니집 | 하루의 시간을 끕니다 |
| 1997 | 라디오 | 다이얼을 돌려 주파수를 찾습니다 |
| 1999 | 워크맨 | 들을수록 테이프가 닳습니다 |
| 2004 | PC방 | 자리를 옮겨 다닙니다 |

일곱 방이 서로 다른 것을 만지게 되어 있습니다. 같은 장난감을 배경만 바꿔
일곱 번 만드는 것을 피하려고 축을 겹치지 않게 나눴습니다.

## 소리에 대해

**방 안의 앰비언스는 전부 브라우저에서 실시간으로 합성됩니다.** 샘플 파일도,
녹음물도, 외부 요청도 없습니다. 매미 울음의 AM 변조, 키보드 소리의 포아송
분포, 잔향의 절차적 임펄스 응답, 테이프의 wow/flutter — 전부 Web Audio 노드
그래프로 그 자리에서 만듭니다.

**음악 레이어만 파일입니다.** 자체 GPU에서 MiniMax-Music3로 생성했고,
라이선스된 상업 녹음물은 한 곡도 쓰지 않았습니다. 각 곡의 조성과 템포는
그 방의 소스코드에 이미 있던 주파수에서 가져왔습니다 — 예를 들어 라디오의
발라드는 `audio.js`의 종소리가 쓰던 A 단조 5음 음계를 그대로 씁니다.
그리고 음악은 방 위에 얹히지 않고 **그 방에 있는 물건에서** 나옵니다.
라디오는 15 kHz에서 잘리고, 위층 롤러장 소리는 바닥을 통과하느라 킥과
베이스만 남습니다.

## 이 저장소에 대해

각 방은 독립 정적 사이트로도 공개돼 있고, 여기에는 사본이 담겨 있습니다.
사본은 손으로 고치지 않습니다 — 원본에서 다시 생성합니다.

빌드 단계도, 의존성도, 백엔드도 없습니다. 정적 파일이 전부입니다.
다만 ES 모듈을 쓰므로 `file://`로 직접 열면 브라우저가 막습니다 —
아무 정적 서버나 하나 띄우면 됩니다(`python3 -m http.server`).
